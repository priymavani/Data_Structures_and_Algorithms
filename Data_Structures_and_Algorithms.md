## ✅ Data Structures and Algorithms (DSA): Definition

**Data Structures (DS)** are **ways of organizing and storing data** so it can be accessed and modified efficiently.

**Algorithms (A)** are **step-by-step procedures or formulas for solving a problem**.

Together, **DSA helps in writing efficient, clean, and optimized code** for solving real-world and computational problems.

---

## ✅ Importance of DSA

* Efficient **memory management**.
* **Faster execution and performance** of programs.
* Essential for **interview preparation and problem-solving**.
* Forms the **foundation for advanced subjects** (DBMS, OS, Networking).

---

## ✅ Types of Data Structures

1️⃣ **Linear Data Structures:**

* **Array**
* **Linked List**
* **Stack**
* **Queue**

2️⃣ **Non-Linear Data Structures:**

* **Tree**
* **Graph**

3️⃣ **Hash-based Data Structures:**

* **Hash Table**
* **Hash Map**

---

## ✅ Algorithms in DSA

Algorithms can be categorized into:

* **Searching Algorithms:** Linear Search, Binary Search
* **Sorting Algorithms:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort
* **Traversal Algorithms:** Tree Traversals (Inorder, Preorder, Postorder), Graph Traversals (BFS, DFS)
* **Divide and Conquer Algorithms**
* **Greedy Algorithms**
* **Dynamic Programming**
* **Backtracking**

## ✅ Basic DSA Complexity Terms

* **Time Complexity:** The amount of time an algorithm takes to run.
* **Space Complexity:** The amount of memory an algorithm uses during execution.
* **Big O Notation (O):** Used to represent the **upper bound (worst-case) of an algorithm**.

Examples:

* Linear Search: O(n)
* Binary Search: O(log n)
* Bubble Sort: O(n²)
